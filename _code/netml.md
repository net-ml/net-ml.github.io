## Overview

NetML is a Python package designed for network traffic analysis using machine learning techniques.

## Installation

Available on PyPI:

```bash
pip install netml
```

## Resources

- **GitHub:** [github.com/noise-lab/netml](https://github.com/noise-lab/netml)
- **PyPI:** [pypi.org/project/netml](https://pypi.org/project/netml/)

## Features

Network traffic analysis toolkit with machine learning capabilities for:
- Traffic classification
- Network measurement
- Security analysis
