# Candidate Publications and Projects: ML Applications to Security and Privacy

This document lists candidate publications and projects from the earlier work on applying machine learning to network security and privacy problems, dating back to 2006.

## 1. Early Spam and Botnet Detection (2006-2012)

### Network-Level Behavior of Spammers (2006)
**Publication:** Feamster2006:spam
- **Authors:** Anirudh Ramachandran, Nick Feamster
- **Title:** Understanding the Network-Level Behavior of Spammers
- **Venue:** ACM SIGCOMM 2006
- **Significance:** Pioneering work applying ML to analyze network-level spam behavior

### DNSBL and Botnet Detection (2006)
**Publications:**
- Ramachandran2006:dnsbl - "Can DNSBLs Keep Up with Bots?" (CEAS 2006)
- Ramachandran2006:recon - "Revealing Botnet Membership with DNSBL Counter-Intelligence" (SRUTI 2006)
- **Authors:** Anirudh Ramachandran, Nick Feamster, David Dagon

### Behavioral Spam Filtering (2007)
**Publication:** ramachandran2007:spamtracker
- **Title:** Filtering Spam with Behavioral Blacklisting
- **Authors:** Anirudh Ramachandran, Nick Feamster, Santosh Vempala
- **Venue:** ACM CCS 2007

### Predicting Bad Behavior (2007)
**Publication:** Syed2007:spamsvm-nips
- **Title:** Predicting Bad Behavior
- **Authors:** Nadeem Syed, Nick Feamster, Alex Gray
- **Venue:** NIPS Workshop on Machine Learning in Adversarial Environments for Computer Security 2007

### Phishing Detection (2010)
**Publication:** Ramachandran2010:fish4phish
- **Title:** Fishing for Phishing in the Network Stream
- **Authors:** Anirudh Ramachandran, Nick Feamster, Kobus van der Merwe, Balachander Krishnamurthy, Oliver Spatschek
- **Type:** Georgia Tech Technical Report (2010)

### Spam/Ham Classification (2011)
**Publication:** Ramachandran2011:ceas
- **Title:** Spam or Ham? Characterizing and Detecting Fraudulent "Not Spam" Reports in Web Mail Systems
- **Authors:** Anirudh Ramachandran, Anirban Dasgupta, Nick Feamster, Kilian Weinberger
- **Venue:** CEAS 2011

### Twitter/Email Spam (2012)
**Publication:** Lumezanu2012:spam
- **Title:** Observing Common Spam in Twitter and Email
- **Authors:** Cristian Lumezanu, Nick Feamster
- **Venue:** ACM IMC 2012

### Domain Registration Behavior (2013)
**Publication:** hao2013:dns
- **Title:** Understanding the Domain Registration Behavior of Spammers
- **Authors:** Shuang Hao, Matthew Thomas, Vern Paxson, Nick Feamster, Christian Kreibich, Chris Grier, Scott Hollenbeck

## 2. SNARE: Spatio-temporal Network-level Automatic Reputation Engine (2009)

**Publication:** Hao2009:snare
- **Title:** Detecting Spammers with SNARE: Spatio-temporal Network-level Automatic Reputation Engine
- **Authors:** Shuang Hao, Nadeem Syed, Nick Feamster, Alexander Gray, Sven Krasser
- **Venue:** USENIX Security 2009
- **Significance:** ML-based reputation system for spam detection using spatio-temporal features
