NetML

The NetML project is dedicated to advancing research and innovation at the intersection of machine learning (ML) and networking. Our mission is to develop cutting-edge solutions that apply ML to optimize network performance, enhance security, and tackle complex challenges in modern computer networks.

Research

We focus on several key areas:

  • Data Representation: Developing efficient and effective representations of network traffic for ML tasks
    • nPrint: Packet-level feature extraction
    • NetML: Feature extraction for novelty detection
  • Synthetic Data Generation: Creating high-fidelity synthetic network data for training and testing
    • NetDiffusion: Protocol-constrained traffic generation
    • NetSSM: State-space models for multi-flow trace generation
  • Multimodal Inference: Combining network data with other signals for robust analysis
    • AMIR: Video quality inference from encrypted traffic
    • CAIP: LLM-based router misconfiguration detection
  • Model Serving and Maintenance: Balancing model accuracy with systems-level deployment costs
    • LEAF: Navigating concept drift in cellular networks
    • CATO: End-to-end optimization of ML pipelines
    • Traffic Refinery: Cost-aware data representation
  • Dynamic Model Execution: Adaptive model selection and scheduling for real-time network analysis
    • JITI: Adaptive ensemble classification
    • ServeFlow: Fast-slow model architecture
    • Cruise Control: Dynamic model selection
